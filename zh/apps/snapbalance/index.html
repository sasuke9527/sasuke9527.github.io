拍小票变报表：复式记账，自动出四张报表

懂会计的记账本 · 告别流水账

「拍小票变报表」（英文名 SnapBalance，曾用名「一拍即账」）是一款 iPhone 复式记账 App，给想把家里的钱记清楚、又不想学会计术语的人用。拍一张小票，或者说一句「昨天超市买菜 85」，它就生成借贷平衡的会计分录；月底自动出四张财务报表。不用注册，数据存在你的手机里；Pro 一次买断，不订阅。

主要功能

  • 拍小票记账：默认用 iPhone 自带的文字识别读出商户、金额、日期和 GST，照片不离开手机；识别有误直接改，改过一次，同一家商户下次自动套用
  • 一句话记账：说话或打字，一次生成多笔带日期、分类和账户的记录，确认后保存；能理解「上周五」「八月某天」这样的相对日期，也能处理借款、还款、取现和存款；语音在手机上转成文字，录音不保存
  • 真复式分录：每一笔都是借贷平衡的会计分录，下面配大白话解释；内置还房贷、买房交割、子女教育储备金、折旧等模板
  • 四张报表：利润表、资产负债表、所有者权益变动表、现金流量表，并带一致性检查
  • 消费分析：分期对比、趋势线和日历视图
  • 识别方式可选：想要更高的识别精度，可以在设置里填入你自己的 API 密钥，改用云端大模型或 Azure 识别

免费与付费

免费版可以手动记账、查看四张报表、使用一个账本，不限时间、没有广告，另外送 10 张小票识别和 5 次一句话记账。Pro 终身版一次买断，解锁不限张数的小票识别、不限次的一句话记账、银行截图批量导入、多账本、变动对比与余额走势、CSV 导出（交易明细和会计分录）、定期自动记账。Pro 绑定 Apple ID，家庭共享成员也能使用。

适合谁

想认真管理家庭账、看清资产负债和现金流的人；不懂会计、但想要一本「真账本」而不是流水账的人；做财务工作、想用熟悉的方法管自己家账的人。日常记账只是「拍一张 → 确认 → 完成」，不会看到借贷术语，只有在手工分录页面才出现借方和贷方。

它不做什么

  • 不连接银行，不提供支付、借贷、投资或理财服务，只是本地记账工具
  • 没有账号和云同步；换手机用 iPhone 的加密备份（iCloud 备份或电脑备份）恢复
  • 目前只有 iPhone 版，支持简体中文和英文

常见问题

我不懂会计，能用吗？

能。日常记账只要拍一张小票再确认，不会看到借贷术语。手工分录页面才出现借方和贷方，每一行都有大白话解释，也有常用模板。第一次打开，可以先在「设置 → 生成样本账本」里看一遍完整的账。

拍小票会把照片上传吗？

默认不会：识别用的是 iOS 自带的文字识别，照片只存在手机里。只有你自己在设置里改用「云端大模型」或「Azure」并填入自己的 API 密钥时，那张票据图片才会从你的手机直接发给你选的服务商，开发者不经手、也看不到。

免费版能做什么？

可以手动记账、查看四张报表、使用一个账本，不限时间、没有广告，另外有 10 张小票识别和 5 次一句话记账的额度。不限量的识别和一句话记账、多账本、CSV 导出等属于 Pro。

换手机了，数据怎么带走？

用 iPhone 自带的加密备份（iCloud 备份或电脑备份）恢复新机，App 数据会一起回来。Pro 用户也可以在「设置 → 导出」导出 CSV。

Pro 是订阅吗？

不是。Pro 终身版一次性购买，绑定你的 Apple ID；重装后在「设置 → 恢复购买」即可恢复，家庭共享成员也能使用。

本 App 是个人开发的本地记账工具，不提供支付、借贷、投资、理财或任何金融服务。
